# 飞机大战（Python / pygame）

经典的纵版射击小游戏，包含玩家战机、多类型敌机、子弹与道具、碰撞与爆炸动画、音效、暂停与最高分记录。

- **技术栈**：Python 3、pygame、面向对象模块化设计
- **类型**：Python 程序设计课程设计
- **目录**：根目录为游戏逻辑（`飞机大战.py` 为主入口），`feiji/` 为图片 / 音频 / 字体素材，`ms_test/` 为分场景实验代码

## 本地运行

```bash
pip install pygame
python 飞机大战.py
```

## 说明

虚拟环境 `.venv/` 未打包，只需安装 pygame 即可运行；`feiji/` 素材必须保留，否则缺少图片与音效。
